# Portfolio template

A responsive, one-page portfolio template built with plain HTML, CSS, and JavaScript. No build step or package installation is needed.

## Run locally

Open `index.html` in a browser, or serve this folder with any static web server.

## Make it yours

1. Replace **Alex Morgan** and the sample bio, location, availability, and studio details in `index.html`.
2. Update the project names, descriptions, years, and email links. The project artwork is CSS-based, so it can be replaced or restyled in `styles.css`.
3. Change `hello@example.com` to your email address and update the social profile links.
4. Adjust the colors and typography in the custom properties at the top of `styles.css`.

The Google Fonts used by the template load over the network; system font fallbacks are included.
